DELIVERY SCANNER - ANDROID PROJECT

1) Install Android Studio on Windows.
2) Open this folder: DeliveryScannerAndroid
3) Let Gradle sync.
4) Select Build > Build Bundle(s) / APK(s) > Build APK(s).
5) The APK will be under:
   app/build/outputs/apk/debug/app-debug.apk
6) Copy the APK to the Android phone and install it.

The app includes:
- Camera / Gallery image selection
- OCR page
- Customer name/phone/order/delivery fields
- WhatsApp
- Daily report
- Local order storage

Note: OCR uses the Tesseract.js CDN, so the phone needs internet when reading a paper.
